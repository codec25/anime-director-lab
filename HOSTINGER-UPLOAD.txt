Live provider requirements:
- RUNWAY_API_KEY=...
- ANIME_DIRECTOR_BASE_URL must point to the public HTTPS app URL.
- ANIME_DIRECTOR_MOCK_MODE=0 for live generation.
- World/scene/shot image, video and audio references must be provider-fetchable public HTTPS URLs.
- Semantic roles available: character, environment, prop, style, motion, voice, sound, reference.
- Provider reference order is mapped into the generation prompt (Image 1, Video 1, Audio 1, etc.) with the saved semantic role.
- Seedance 2.5 native reference generation is the preferred path when World Memory or shot references are active.
- Scene Memory overrides only filled fields; empty scene fields inherit World Memory.
- Location Presets are reusable copies; applying one does not create a live link back to the preset.
- New shots are bound to the currently active scene and inherit its scene references/environment plates.
- Cast + Voices supports multiple recurring characters. The locked Character Bible remains the primary cast member; secondary cast members can store their own identity image and voice reference.
- Every dialogue line stores speaker_id and speaker_name, so dialogue turn order and generated speech stay assigned to the correct recurring character.
- Runway Seed Audio is used per dialogue turn. Each generated clip is stored as a semantic `voice` reference with the speaker identity attached.
- Reference-aware video generation automatically includes identity references for the characters speaking in that shot and labels voice references with the named speaker in the prompt.
- Exact multi-character mouth/facial performance still requires separate ACT IT / Act-Two passes per speaking character. Runway Act-Two currently controls one isolated character at a time; compositing those passes is a later orchestration step.
- Native continuation uses the previous generated video and requires a provider-fetchable public HTTPS URL.
- Seedance 2.5 input/reference videos must be at least 480p.
